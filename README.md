# Bankly

A full-stack banking application built as a portfolio project, simulating real-world financial operations: accounts, transactions, transfers between accounts, and statements.

> This is a personal study/portfolio project and is not affiliated with the company Bankly (Banking as a Service).

## Tech Stack
- **Backend:** ASP.NET Core / C#
- **Frontend:** React
- **Database:** PostgreSQL
